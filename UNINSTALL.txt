StudyQuest 제거 방법

1. 실행 중인 StudyQuest를 종료합니다.
2. 압축을 풀어 둔 StudyQuest 폴더 전체를 삭제합니다.

앱 본체, 빌드 소스, 포터블 실행 파일, 앱 상태, 캐시, 로그, 세션, 임시 파일은 이 폴더 안에 있습니다.
레지스트리, 시작 프로그램, Windows 서비스, Program Files 등록은 만들지 않았습니다.

단, StudyQuest가 사용하지 않는 Claude 구독 로그인, 별도로 설치한 Claude CLI 프로그램, Codex가 관리하는 로그인 정보는 원래 Windows 사용자 영역에 있으므로 이 폴더를 삭제해도 그대로 남습니다.
기본 데이터 위치를 사용했다면 StudyQuest에 저장한 개인 API 키 암호문도 앱 폴더와 함께 삭제됩니다.
설정에서 별도의 데이터 폴더를 선택했다면 그 폴더는 자동으로 삭제되지 않으므로 직접 확인해야 합니다.
Windows 자체가 만든 Prefetch·Defender·이벤트 기록은 운영체제 관리 영역이며 이 폴더 삭제 대상이 아닙니다.
